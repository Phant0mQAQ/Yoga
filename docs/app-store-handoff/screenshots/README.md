# App Store Screenshot Checklist

截图必须来自最终 TestFlight 构建，显示真实、准确、无测试水印的当前 UI。本交付包不使用 Web 管理后台截图冒充 iPhone App 截图。

## 数量与格式

- 每种本地化可上传 1 至 10 张。
- 格式：PNG、JPEG 或 JPG。
- 不得包含透明通道。
- 本项目只支持 iPhone 竖屏，不需要 iPad 截图。

## 当前 Apple 接受的 6.9 英寸竖屏尺寸

任选 Apple 当前允许的一组：

```text
1260 x 2736
1290 x 2796
1320 x 2868
```

Apple 会随设备更新规格，提交当天请再次检查官方页面：

https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/

## 建议截图顺序

1. Student 首页和课程推荐。
2. 课程预约列表，显示余位和参与者头像。
3. 课程详情与确认预约。
4. 我的预约和会员卡。
5. Coach 排课或可预约时间。
6. Staff 今日课程与核销。
7. Admin Dashboard。
8. Admin 会员/排课/内容管理之一。

分别准备 `en-US`、`zh-Hans`、`ko` 三套截图。截图中不要出现真实客户姓名、手机号、邮箱、体测数据或真实支付记录。
